## 📌 Descripción

FNR Sistema de Gestión de Clientes es una solución administrativa integral diseñada para optimizar y centralizar la información de los clientes, mejorando la eficiencia operativa y la toma de decisiones. Construido con tecnologías modernas (Next.js y Supabase) para garantizar rendimiento, escalabilidad y seguridad.

## 🚀 Características Principales

- **Gestión de Clientes:** CRUD completo con interfaz intuitiva.
- **Autenticación Segura:** Sistema de login y manejo de sesiones.
- **Base de Datos en Tiempo Real:** Integración con Supabase.
- **Diseño Responsivo:** Interfaz adaptable a cualquier dispositivo.

## 🛠 Tecnologías Utilizadas

- **Frontend:** Next.js, React, Tailwind CSS (si aplica)
- **Backend/BaaS:** Supabase
- **Lenguaje:** TypeScript / JavaScript
- **Herramientas de Calidad:** ESLint

## 📦 Instalación y Configuración Local

Sigue estos pasos para levantar el entorno de desarrollo local:

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/bastiascid/FNR-sistema_de_gestion_clientes.git
   cd FNR-sistema_de_gestion_clientes
   ```

2. **Instala las dependencias:**
   ```bash
   npm install
   ```

3. **Configura las variables de entorno:**
   Crea un archivo `.env.local` en la raíz del proyecto y agrega tus credenciales de Supabase:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=tu_url_de_supabase
   NEXT_PUBLIC_SUPABASE_ANON_KEY=tu_anon_key_de_supabase
   ```

4. **Inicia el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

   Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver la aplicación.
