# Guía de Contribución

¡Gracias por tu interés en contribuir a este proyecto!

## Proceso de Contribución

1. Haz un Fork del repositorio.
2. Crea una rama para tu feature (`git checkout -b feature/NuevaCaracteristica`).
3. Sigue la convención de [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) para tus commits.
4. Haz push a la rama (`git push origin feature/NuevaCaracteristica`).
5. Abre un Pull Request.

## Estilo de Código

- Utiliza ESLint y Prettier (si está configurado) antes de hacer commit.
- Escribe código limpio y bien documentado.
- Añade comentarios a secciones complejas.

## Reporte de Bugs

Si encuentras un bug, por favor abre un issue detallando:
- Comportamiento esperado.
- Comportamiento actual.
- Pasos para reproducir el bug.
- Entorno (SO, navegador, versión, etc.).
